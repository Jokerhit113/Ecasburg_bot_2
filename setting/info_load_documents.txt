📋 Документы для растаможки автомобиля: полный список
Для быстрого прохождения таможни подготовьте следующие документы:
📄 Личные документы:
1.	Паспорт РФ (разворот с фото + прописка)
2.	ИНН
3.	СНИЛС
4.	Водительское удостоверение (серия и номер)
🚗 Документы на авто:
1.	Договор купли-продажи (с подписью)
2.	Инвойс (счет на оплату)
3.	Подтверждение оплаты автомобиля (чек с отметкой о выполнении платежа)
4.	Выписка по валютному счету (с даты оплаты)
5.	Справка о движении средств по валютному счету
6.	Квитанция об оплате таможенной пошлины
🔍 Дополнительно:
•	Нотариально заверенная копия паспорта (разворот с фото + регистрация)
•	Регистрация в системе ЭПТС (через Госуслуги)
•	Скриншот личного кабинета ЭПТС
✔ Требования к сканам:
•	Четкое изображение без бликов
•	Все углы документа должны быть видны
•	Белый фон (лист А4)
•	Лучше использовать сканер, а не фото с телефона
•	Никаких посторонних предметов в кадре
ℹ Дополнительная информация (нужно указать):
•	Ваш адрес проживания
•	Контактный телефон и e-mail
•	Данные о ранее ввезенных автомобилях (если были)
•	Информация о других авто в собственности
🔗 Ссылка для регистрации в системе ЭПТС: https://dp.elpts.ru/#/auth/
